# Aula 03 — Referencial Teórico e Trabalhos Relacionados

## Objetivos da aula

Ao final desta aula, o aluno deverá ser capaz de:

- organizar o referencial em torno do problema;
- selecionar conceitos realmente necessários;
- localizar e analisar trabalhos relacionados;
- comparar estudos anteriores;
- identificar a posição do próprio trabalho na literatura.

---

# 1. Função do Referencial

O Referencial Teórico fornece a base conceitual necessária para compreender o trabalho.

Os Trabalhos Relacionados mostram o que já foi feito sobre o problema.

---

# 2. Pergunta central

> **O que já sabemos sobre este problema?**

---

# 3. Estrutura recomendada

```text
2 REFERENCIAL TEÓRICO E TRABALHOS RELACIONADOS

2.1 Contexto do problema

2.2 Conceitos fundamentais

2.3 Métodos, modelos ou tecnologias relevantes

2.4 Trabalhos relacionados

2.5 Comparação dos trabalhos

2.6 Síntese e posicionamento do TCC
```

---

# 4. O referencial não é um dicionário

Evite organizar o capítulo apenas como uma sequência de definições.

Exemplo inadequado:

```text
2.1 Internet
2.2 HTML
2.3 CSS
2.4 Java
2.5 Banco de Dados
```

A estrutura deve ser orientada pelo problema de pesquisa.

---

# 5. Conceitos fundamentais

Inclua apenas conceitos necessários para compreender:

- o problema;
- a solução;
- o método;
- os resultados;
- a discussão.

---

# 6. Trabalhos relacionados

Para cada trabalho relevante, observe:

- objetivo;
- contexto;
- método;
- abordagem;
- forma de avaliação;
- resultados;
- limitações.

---

# 7. Tabela comparativa

Uma tabela comparativa ajuda a organizar os estudos.

| Trabalho | Objetivo | Método/Abordagem | Avaliação | Limitação |
|---|---|---|---|---|
| Autor A | ... | ... | ... | ... |
| Autor B | ... | ... | ... | ... |
| Autor C | ... | ... | ... | ... |

---

# 8. Fontes recomendadas

Priorize:

- artigos científicos;
- periódicos;
- conferências;
- livros acadêmicos;
- normas;
- documentos técnicos confiáveis.

Evite fundamentar conceitos centrais apenas em:

- blogs;
- tutoriais;
- páginas comerciais;
- sites sem autoria identificada.

---

# 9. Literatura clássica e recente

Uma boa revisão pode combinar:

- trabalhos clássicos para conceitos consolidados;
- literatura recente para mostrar o estado atual.

A escolha deve considerar relevância, e não apenas data.

---

# 10. Síntese do capítulo

O capítulo deve terminar mostrando:

```text
O que já existe?
        ↓
Quais limitações permanecem?
        ↓
Onde este TCC se posiciona?
```

---

# 11. Erros frequentes

Evite:

- excesso de definições;
- referências pouco relacionadas ao problema;
- apenas resumir artigo por artigo;
- não comparar estudos;
- usar poucas fontes científicas;
- não identificar limitações da literatura.

---

# 12. Checklist

- [ ] Os conceitos essenciais estão presentes?
- [ ] O capítulo está orientado pelo problema?
- [ ] Os trabalhos relacionados são realmente próximos ao tema?
- [ ] Existe comparação entre os estudos?
- [ ] As limitações da literatura estão claras?
- [ ] O posicionamento do TCC está explícito?

---

# 13. Produto esperado

Ao final da aula, o aluno deve ter:

1. a estrutura do referencial;
2. os principais conceitos selecionados;
3. um conjunto inicial de trabalhos relacionados;
4. uma tabela comparativa;
5. uma síntese mostrando onde o TCC se posiciona.
