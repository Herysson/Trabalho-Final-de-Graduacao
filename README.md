# Sequência das Aulas — Construção de TCC em Computação

## Ordem adotada

As aulas seguem a ordem pedagógica de construção do trabalho:

```text
Aula 01 — Visão Geral

Aula 02 — Introdução
        ↓
Aula 03 — Referencial Teórico e Trabalhos Relacionados
        ↓
Aula 04 — Metodologia
        ↓
Aula 05 — Resultados
        ↓
Aula 06 — Discussão
        ↓
Aula 07 — Conclusão
        ↓
Aula 08 — Resumo
```

## Observação

A escrita é iterativa.

Introdução, Referencial e Metodologia podem ser revisados depois que os resultados e a discussão estiverem consolidados.
